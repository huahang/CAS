## 正文核对

镜像按各文件来源注释和正文清单对应所选官网网页或原始附件. 网页转写保持原有文字及标点, 只增加 Markdown 标题、段落和表格排版. 网页通知只有通知文字而没有解释全文时, 后接该通知原始附件的全文, 两部分来源分别记录. 保留原文全角标点, 不将仓库说明文的半角标点约定用于改写法规原文.

逐字核验覆盖全部 80 份镜像的 365,690 个非空白字符, 文字、数字和标点均与各自标明来源一致. 比较只排除来源注释、Markdown 标记、HTML 标签和 Unicode 排版空白, 不归一化汉字、数字、括号、破折号或其他标点. 结果见[逐字核对结果](逐字核对结果.json).

核对脚本独立使用 Python 标准库 HTML 解析器读取原始网页正文, 对原件再次提取文字, 不仅比较生成时保存的文本或文件是否存在. 第 10 号准则的两个表格另比对行列和合并单元格结构. DOC 镜像用 antiword 的普通文本输出交叉检查 DocBook 转写; DOCX 镜像用原始 XML 核对文字, 并检查自动编号. 21 份作为镜像来源的 PDF 共 165 页, Poppler 与 pypdf 的文字提取结果经排版空白处理后一致.

解释第 16 号原 PDF 第 1 页的标点基线造成 Poppler 布局模式将"称适用本解释的单项交易）"放错顺序. 已依据[原件版面](版面核对/解释第16号-第1页.png)和 PDF 原始内容流校正阅读顺序. 校正前后片段和原因保存在正文清单, 不改动原 PDF 字节, 也不改写原文措辞.

## 网页与附件的差异

另外对 74 份单独附件与对应镜像进行交叉比较: 59 份正文文字相同, 14 份出现网页异文或 Word 编号/附加文字的提取差异, 1 份为没有可提取文字的扫描 PDF. 这些比较不包含原始 RAR 包本身. [网页附件比对记录](网页附件比对.json)保留完整差异, 不把机械提取差异直接当作正式修订.

实际差异包括基本准则 2006 年版的"作/做"、第 22/23/24/37/39 号部分措辞及标点. 第 2 号 2014 年版 Word 提取在第七条前多出"一揽子交易处理"文字; 第 21 号 2018 年版 Word 使用 17 处自动编号, 普通段落文本提取不会显示这些编号. 第 33 号 2014 年版 PDF 为扫描件, 镜像采用同一印发通知的官网完整正文.

这部分文件的镜像明确以所标注官网网页为依据, 原附件另完整保存, 不混合两种来源改写成第三种正文. 因而"镜像逐字一致"指与其标明的来源一致, 并不声称官网网页与所有附件互相逐字相同. 本记录也不把官网网页异文推定为另一个正式修订版本.

## 复核方式

运行 `python3 工具/核对文档.py`. 需要 Python 3、Poppler 的 `pdftotext`、antiword 和 unrar-free. 工具不在 PATH 时, 可用 `CAS_ANTIWORD`、`ANTIWORDHOME` 和 `CAS_UNRAR` 指定位置.

脚本核对原网页、重新读取原件、Markdown 字符、表格结构、原件哈希、压缩包成员、文件命名、版本集合及 README 链接覆盖. 本次命令结果为 `逐字一致 80 / 80 附件哈希一致 75 README独立官网URL 95`. 同时执行 `git diff --check`, 通过.
