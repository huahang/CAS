## 索引说明

- 准则按编号一行列示, 共 43 行: 序号 0 为基本准则, 序号 1-42 对应具体准则第 1-42 号. 条目总数包含已废止或被替代的准则, 不等同于现行准则数量.
- 准则名称省略共同前缀, 如序号 1 的"存货"为《企业会计准则第1号——存货》. "现行版本"列列示核验日仍适用的版本; 已发布但待分批施行的新版列入"更新 / 废止情况"列. 第 25/26/30 号的适用范围见附注.
- 表内 2006 年制定的具体准则均由[财会[2006]3号][cas-2006]于 2006-02-15 印发, 自 2007-01-01 起在上市公司范围内施行, 鼓励其他企业执行. [原始附件通知](https://www.mof.gov.cn/zhengwuxinxi/zhengcefabu/2006zcfb/200805/t20080519_23108.htm)中的 38 个 PDF 已逐个入库, 并保留[原始压缩包](<附件/企业会计准则(2006年版).rar>).
- 解释按第 1-20 号升序列示. 日期统一采用通知落款的印发日期, 不采用网页发布日期; 解释的施行日期和条款替代情况按原文件及后续规定判断.
- 链接统一标为"官网", "通知", "正文"或"附件". 现行版本, 文号和链接分列; 本地正文及附件与对应版本列在同一行. 更新 / 废止情况列的 `-` 表示未列其他版本.

## 附注

1. **第 30 号的分批执行安排**: [财会〔2026〕11号](https://kjs.mof.gov.cn/zhengcefabu/202608/t20260805_3994927.htm)于 2026-07-24 印发. 2026 年版自 2027-01-01 起适用于境内外同时上市的企业及境外上市且采用国际财务报告会计准则或企业会计准则编报的企业; 其他境内上市企业自 2029-01-01 起执行; 执行企业会计准则的非上市企业自 2030-01-01 起执行. 允许提前执行. 核验日 2026-10-01, 2026 年版已发布但尚未到首批强制执行日; 提前执行企业采用新版, 其他企业继续采用 2014 年版. 企业执行新版后不再执行 2014 年版.
2. **第 25/26 号的衔接安排**: [财会〔2020〕20号](https://kjs.mof.gov.cn/gongzuodongtai/202012/t20201223_3636695.htm)于 2020-12-19 印发. 新保险合同准则自 2023-01-01 起适用于通知规定的境内外同时上市及境外上市企业, 其他执行企业会计准则的企业自 2026-01-01 起执行, 并允许提前执行. 企业执行新版后不再执行旧第 25 号《原保险合同》, 第 26 号《再保险合同》及财会〔2009〕15号. [财会〔2025〕12号](https://kjs.mof.gov.cn/zhengcefabu/202506/t20250612_3965538.htm)另规定, 确有困难需暂缓执行的保险公司应在 2025-06-30 前向财政部会计司和金融监管总局机构监管司局提交书面材料说明原因, 并在暂缓期间的财务报表附注中披露情况和原因. 原通知未规定所有暂缓企业统一的结束日期, 不能将旧第 25/26 号一概标为于 2026-01-01 全面失效. 第 26 号因此保留为被替代的历史条目, 同时标明暂缓执行企业的适用情况.
